02 / TechnologyTwo technologies · one loop

Simulate it.
Then watch it.

We work on two technologies that depend on each other. Warp pipelines run an operation and its conditions thousands of times at once on a GPU. Anomaly detection models learn what normal looks like in that operation and those conditions, and flag and explain anything that departs from it.

Technology 01 · Warp pipelines

Thousands of operations and conditions at once

the simulator

We turn a simulation's rules and physics into GPU kernels. Each GPU lane holds one complete copy of the operation and its conditions, so one machine steps thousands of copies in parallel. The engine stops being the bottleneck and becomes a viewer for whichever copy you want to watch.

Throughput5.05M world-steps / sec

03 / The conceptA way to picture it

Lightning,
frozen in glass.

Picture a lightning bolt caught inside a block of glass. It happened in an instant, but now all of it is visible: where it struck, how it branched, and what it touched along the way.

A fault in running software leaves the same kind of mark. When code executes in a way it shouldn't, the system's telemetry shifts. Because we extend the engine to produce that telemetry ourselves, we know where each signal comes from and what it measures, so the mark can be read backward from the symptom to the place it began.

The bolt

An execution fault: code doing something it shouldn't.

The glass

Telemetry from an engine we instrument, so every signal has a known origin and meaning.

The trace

Following the mark backward, from where it was noticed to where it began.

A concept, not a finished mechanism. We start with the simple version, test it hard, and get more precise as we scale.
