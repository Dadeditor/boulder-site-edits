Astrolabe.
Agents that work where you work.

Astrolabe is a hosted, subscription agent service: always-on assistants for messaging and productivity tools. It is an adjacent hosted product, not a Boulder Research research project.

Visit astrolabe.miniloader.ai ↗ How it relates
01 / What it isHosted agents

Assistants that
stay on.

Astrolabe agents live in Slack (DMs, channels and threads) and work across your email, calendar, files and code. They keep memory, run scheduled jobs and have their own sandboxed computer.

Messaging

Slack DMs, channels and threads.

Email & calendar

Gmail, Google Calendar, Contacts and Outlook.

Files

Google Drive, OneDrive and Dropbox.

Code

GitHub commits, pushes and pull requests.

It connects to Claude, ChatGPT, Slack, Microsoft 365, Google Workspace, GitHub, Dropbox and the Nous Research Hermes agent, and runs on the Hermes agent stack.

02 / StatusUpdated November 2026

Working product.
Early days.

Signup, Stripe billing and prepaid API keys work. Pricing on the site is $8.99/month for the first three months, then $14.99/month. The live portal is at astrolabe.miniloader.ai, a staging domain; there is no standalone production domain yet. We make no claims about customers or traction.

03 / How it relates to Boulder ResearchStated plainly

Adjacent,
not a research project.

Astrolabe is the hosted counterpart to Miniloader, which runs locally on your own hardware. Both are built on the same agent stack. Miniloader is a Boulder Research research project that ships; Astrolabe is a separate hosted product beside it.
