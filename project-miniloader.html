Miniloader.
AI on your own hardware.

Miniloader is a research project of Boulder Research that ships: a visual control panel for running agents, models and tools on your own machine. You slot in modules, they wire themselves up, and every one shows its status live.

Visit miniloader.ai ↗ How it works
01 / What it isLocal AI

Run it
where your data lives.

Miniloader runs agents, models and tools on your own hardware. Its work feeds the on-prem story at Boulder Research, where customers need AI that runs on their own machines.

Agents, models, tools

Self-hosted

02 / How it worksModules, wired up

Slot in modules.
They wire themselves up.

Miniloader is a rack of modules that plug into one another: an orchestration loop on top, a model backend underneath, then the tools, the database and the files. Pick a preset, add the modules you need, and the panel makes the connections. Each module reports its status live, so you can see what is running and where a request went.

Agent Engine

The orchestration loop for chat turns, tool calls and streamed responses. It expects an OpenAI-compatible model backend upstream.

Local Brain

Local inference: GGUF models loaded through llama.cpp, run in its own process so a crashed model does not take the panel down.

Cloud Brain

An in-process LiteLLM gateway that presents cloud providers as the same OpenAI-compatible endpoint the local modules use.

LiveKit Voice

Realtime speech in and out — speech-to-text and text-to-speech.

Installatron

Installs and auto-configures OpenClaw against your local AI server setup.

Ngrok Tunnel

Publishes a local service with a public URL, and reports the tunnel's status.

Seventeen modules ship with it: Local Brain, Chat Terminal, GPT Server, Database, File Access and the rest. A model runs locally, in the cloud, or both, side by side in the same panel.

03 / The agents it runsNot another agent

Plug in the agent
you already use.

Miniloader is not an agent of its own. It is the engine underneath one: the agent talks to the panel, the panel routes the turn to a model — local or cloud — and hands the tools back.

Hermes Agent

NousResearch's instruction-tuned agent.

OpenClaw

Personal assistant with desktop, tools and workflows.

OpenCode · Aider · Goose

Open-source coding agents, terminal and CLI.

Cline · Roo Code · Kilo Code

Bring-your-own-key agents in VS Code and JetBrains.

LangChain

Frameworks that compose LLM applications.

04 / Where it isEarly access

Local for the routine work,
premium tokens for the rest.

The point is to stop burning premium tokens on work a local model can do. Presets and auto-wiring get you running in minutes, with full visibility into what each turn used. It ships working examples — AC Coach, real-time AI coaching for Assetto Corsa — and is in early access on its own domain, miniloader.ai, not on boulderresearch.ai.
